Everyone is welcomed to submit patches or report the stipend via pull requests or by opening an issue on GitHub.

Why we prefer issues

We encourage submitting datapoints through issues because they facilitate public discussion. They also let us create a hyperlink on the verified checkmark that directs to the corresponding issue. In most cases, we will respond to a submitted issue within a few days.

You may also want to read the FAQ first — it covers how data is collected and which documents we accept.

What happens after you submit

The DeepSeek Harness PR Assistant automatically reviews new issues and drafts CSV changes as a pull request. You can also trigger a re-run by commenting /dsh (or /deepseek) on any issue or pull request.

Getting a verified checkmark

Source documents are optional but encouraged — if you share a link or upload a (redacted) copy, we can add a verified checkmark on the website. See the FAQ for the documents we currently accept, and the labels and icons page for what the checkmarks mean.

Public discussion

We believe issues and comments should be discussed and resolved publicly on GitHub for transparency. If you believe any data is inaccurate or have additional comments, please open an issue or a pull request. The maintainers will not respond to private messages sent to their personal or university accounts regarding this website.
